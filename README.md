# Udemy Clone (HTML & CSS)

## Project Overview
This project is a static, front-end clone of the **Udemy** course platform homepage. It was built as a portfolio piece to demonstrate proficiency in foundational web development technologies.

The goal was to replicate the visual design, layout structure, and responsiveness of the live site using only HTML and CSS.

## 🌟 Features
* **Pixel-Perfect Design:** Accurate reproduction of the key sections of the Udemy landing page.
* **Semantic HTML5:** Structured using modern, semantic elements for improved accessibility and SEO.
* **Responsive Layout:** Uses **CSS Flexbox** and **CSS Grid** to ensure the page looks clean and functional across different screen sizes (desktop, tablet, and mobile).
* **Modern Styling:** Implementation of custom fonts, shadow effects, and hover transitions for a polished look.

## 🛠️ Technologies Used
| Technology | Category |
| :--- | :--- |
| **HTML5** | Structure |
| **CSS3** | Styling & Layout |
| **Flexbox** | Responsive Design |
| **CSS Grid** | Complex Layouts |
